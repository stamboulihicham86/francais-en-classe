# Le français en classe

Site statique pédagogique gratuit pour les élèves, sur téléphone et ordinateur.

## Contenu
210 fiches de préparation : 30 par niveau, de A0 à C2. Chaque fiche contient un objectif, une découverte, une activité, une production, une évaluation et des ressources de référence.

**Statut :** ces fiches sont des trames à valider, pas 210 cours complets. Les contenus de manuels sous droits ne sont pas reproduits. Les vidéos proposées nécessitent une vérification des droits et de la pertinence.

## Publication
Settings → Pages → Deploy from a branch → main → /(root).

## Données
Aucune donnée personnelle d'élève n'est collectée par le site statique.
